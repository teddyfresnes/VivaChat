# Vivachat
### Description
Petit projet test node.js de messagerie en temps réel
- Voir les personnes connectés en temps réel sur le site
- Possibilité d'engager la discussion
- Profil et conversations enregistrés en Local Storage, import et export du profil possible
- Personnalisation du profil
- Gestion de l'absence pour la priorité sur un onglet uniquement, ainsi que pour les notifications
- Vue client sur http://vivachat.ct.ws
